## About

I build AI systems that run on your own infrastructure: from the model and the GPU to the API, the dashboard, the deployment and the security around all of it.

Most AI projects stop at a working model. The hard part comes after: keeping data private, making the system reliable, explaining its decisions, and keeping it secure in production. That's the part I focus on.

My most complete work is a real-time AI platform built as a distributed system. A local vision-language model judges what the cameras see, an agentic memory layer retrieves similar past cases before any expensive call, and a human makes the final decision. It runs on a hardened Linux host, with Terraform-managed Azure infrastructure, full observability, and security checks on every commit.

MSc in Data Engineering & Cloud Computing (aivancity Paris) and Software Engineering diploma (ISGA). I work in English and French.
